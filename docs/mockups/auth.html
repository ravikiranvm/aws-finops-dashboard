finops v3 — Auth screens

Terminal mockups for the authentication flow of finops. Interactive screens are shown at full size — 80 columns by 24 rows — so the chrome, the breathing room, and the density are all real. Colour is applied by meaning, never decoration.

Rendered inline at a terminal. Every one shares the same frame.

Screen 4

Expired session

Auth failure is not a screen you navigate — it prints and exits. The message states the failure once, then the exact commands to recover. Exit code 3 means auth, distinct from a generic failure.

finops audit — expired
$ finops audit
✗ IAM Identity Center session "acme-sso" expired 42m ago.

  Fix:   aws sso login --sso-session acme-sso
  Then:  finops audit

  Or:    finops --profile prod

$ echo $?
3

Screen 6

JSON error — what an agent receives

The remediation field is the difference between an agent recovering on its own and an agent giving up. Errors go to stderr; the exit code carries the category.

finops audit --format json
$ finops audit --format json
{
  "error": {
    "code": "auth_expired",
    "message": "IAM Identity Center session \"acme-sso\" expired 42m ago",
    "remediation": "aws sso login --sso-session acme-sso"
  }
}
$ echo $?
3

Colour semantics

Every colour carries one meaning and only that meaning. Two rules govern use: never colour alone — each signal also carries a glyph (✓ ✗ ⚠ ▲▼) — and apply by meaning, not magnitude, since a cost rise and a savings figure can be the same number with opposite valence.

  • negative
    Cost increased, errors, budget breached, credentials expired.
  • positive
    Cost decreased, savings available, success and checkmarks.
  • warning
    Stale data, approximate figures, a session about to expire.
  • accent
    Commands, keyboard shortcuts, interactive hints, bar charts.
  • dim
    Labels, secondary info, timestamps, unavailable options.
  • text
    Primary content — the values the operator came to read.
  • selection
    Background of the currently highlighted row.
  • border
    Frames and rules; structure without drawing attention.
